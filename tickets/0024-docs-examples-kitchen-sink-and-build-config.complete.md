# Ticket 0024: Complete Docs, Updated Skill, Folder Verification, Graceful Script Errors, Build Targets & Examples, Lua Examples, Kitchen-Sink Demo, First-Run Tutorial, and Custom Root Config

## Overview
Bring Project Engine to a polished, production-ready developer and game-authoring experience across documentation, agent tooling, startup safety, runtime resilience, build/packaging workflows, Lua examples, a comprehensive kitchen-sink demo scene, an interactive first-run tutorial, and configurable project root directories.

## Functional Requirements
1. **Complete & Up-to-Date Docs**: Update `README.md`, `docs/` guides (architecture, building & distribution, Lua scripting), and runtime `docs_registry.go` introspection so all packages, CLI flags, workflows, and APIs are accurately documented.
2. **Up-to-Date `use-project-engine` Skill**: Update `skills/use-project-engine/SKILL.md` and `skills/use-project-engine/examples/` to cover the default executable (`bin/project-engine`), `--root`/`--config`/`--init-dirs` flags, folder verification, graceful script error reporting, and current runtime capabilities.
3. **Folder Structure Verification on Load**: Verify required project directories (`assets/`, `scripts/`, `prefabs/`, `config/`) under the configured root on startup, failing fast with clear diagnostic instructions when missing, and supporting `--init-dirs` to scaffold a new game root.
4. **Graceful Script Error Handling**: Ensure `LoadScriptsDir`, `ScriptComponent`, `LuaComponent`, `PropRegistry`, and `cmd/demo` never crash or abort loading remaining scripts on Lua syntax/runtime errors; record and surface errors clearly in the Developer Console and ImGui overlay.
5. **Examples for Building the Engine AND Creating a Build**: Provide working scripts and documentation in `examples/build/` (plus `examples/custom-game-root/`) demonstrating both compiling the engine executable and assembling a standalone distributable game build.
6. **Lua Examples**: Add runnable, well-documented Lua examples in `examples/lua/` (shell commands, custom components, prefabs/events, Jolt physics/raycasting, LuaJIT zero-alloc HUD) plus an active example component in `scripts/components/`.
7. **Kitchen Sink Demo Scene**: Upgrade `cmd/demo` to showcase a sample TMX 3D tile map (`assets/maps/kitchen_sink.tmx` rendered via `pkg/tileimporter`), all 4 props (`rainbow_cube`, `kitchen_toaster`, `lamp_ceramic`, `nightstand_drawer`), Jolt physics/colliders, interactive/fracture controls, custom Lua component motion, and 2D HUD overlays.
8. **First-Run Tutorial with "Do Not Show Again"**: Add a Dear ImGui welcome tutorial window shown on first run with a persisted `"Do not show again"` checkbox stored under the configured `config/` directory (`tutorial_state.json`), reopenable via UI button or `tutorial` console command.
9. **Default Build Target for Engine Executable**: Provide a root `Makefile` (default target `build`), `build.ps1`, and `build.sh` that build `cmd/demo` into `bin/project-engine(.exe)` with `CGO_LDFLAGS_ALLOW` configured.
10. **Config & CLI Option for Custom Game/Script/Config/Data Root**: Support `--root <dir>`, `--config <file>`, and `engine.json` to redirect `assets/`, `scripts/`, `prefabs/`, and `config/` to any external directory.
